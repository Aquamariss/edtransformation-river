# Пульс реки — запуск

Страница `/pulse/` — анкета и общий график. Ответы хранятся в Google Таблице
«Река времени 10 лет - ответы». Цепочка: страница → функция Netlify `/pulse/api` → Apps Script → Таблица.

## 1. Закрыть доступ к Таблице по ссылке

Сейчас Таблицу может **редактировать любой, у кого есть ссылка**. Это значит, что посторонний
может прочитать организации, испортить данные и открыть скрипт с ключом.
«Настройки доступа» → «Общий доступ» → **«Доступ ограничен»**. Личные доступы коллег можно оставить.

## 2. Apps Script

1. В Таблице: **Расширения → Apps Script**.
2. Удалите содержимое файла `Код.gs` и вставьте целиком `pulse/apps-script/Code.gs` из репозитория. Сохраните (💾).
3. В списке функций вверху выберите **`setup`** → **Выполнить**. Google попросит разрешения — разрешите
   (вход в аккаунт → «Дополнительные настройки» → «Перейти к проекту» → «Разрешить»).
4. После выполнения откройте **Журнал выполнения** внизу: там ключ `PULSE_SECRET` (64 символа). Скопируйте его.
   Позже ключ можно посмотреть в самой Таблице: меню **Пульс → Показать ключ для Netlify**
   (меню появляется после перезагрузки Таблицы).
5. **Начать развёртывание → Новое развёртывание** → тип «Веб-приложение»:
   - Описание: `pulse`
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
   → «Начать развёртывание» → скопируйте **URL веб-приложения** (заканчивается на `/exec`).

> Если позже меняете код скрипта: **Начать развёртывание → Управление развёртываниями → ✏️ → Версия: «Новая версия» → Развернуть.**
> Не создавайте новое развёртывание — у него будет другой адрес.

## 3. Netlify

**Site configuration → Environment variables → Add a variable** (для всех контекстов):

| Ключ | Значение |
|---|---|
| `PULSE_SCRIPT_URL` | URL веб-приложения из шага 2.5 |
| `PULSE_SECRET` | ключ из шага 2.4 |

Затем **Deploys → Trigger deploy → Deploy site** (переменные подхватываются при новой сборке).

## 4. Проверка

Откройте `https://edtransformation-river.netlify.app/pulse/`, отправьте тестовый ответ — он появится
в листе «Ответы» и на графике. Тестовые строки удалите вручную.

## Модерация в Таблице

- **Удалить ответ** — удалите строку в листе «Ответы». Его свои сдвиги перестанут учитываться автоматически.
- **Объединить похожие свои сдвиги** — в листе «Свои сдвиги» впишите одинаковое значение в столбец
  «Каноническое название». Исходный текст остаётся.
- **Скрыть свой сдвиг** — галочка «Скрыть». Ответы с ненормативной лексикой приходят уже скрытыми.
- **Закрыть приём** — лист «Настройки», снимите галочку «Приём ответов открыт». График продолжит работать.
- Лимиты (2 ответа с устройства, 20 с IP за сутки, 50 всего за час) меняются там же.
- Правки в Таблице попадают на график за несколько секунд (кеш до 20 с в скрипте и до 15 с на Netlify).
- Не переименовывайте заголовки столбцов. Свои столбцы можно добавлять справа.
