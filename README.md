# Река времени · Трансформация образования

Интерактивный маршрут доклада Марины Семехиной «Трансформация образования: где мы находимся» (Кафедра Гудлайн · 10 лет).

Один самодостаточный файл `index.html`: шрифты и генератор QR-кода встроены, внешних запросов нет. Открывается в любом браузере.

Управление: стрелки / пробел — дальше, колесо — масштаб, `O` — вся карта, `Q` — QR-код, `F` — полный экран.

## Пульс аудитории — `/pulse/`

Отдельная страница-опрос в том же стиле: анкета (тип образования, стадия по семи сдвигам, свои сдвиги, организация) и общий график по всем ответам с фильтром по типу образования. Ответы пишутся в Google Таблицу через функцию Netlify `netlify/functions/pulse.mjs` и Apps Script `pulse/apps-script/Code.gs`. Запуск и модерация — в `pulse/SETUP.md`.
